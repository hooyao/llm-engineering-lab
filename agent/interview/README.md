# Applied Agent Interview Labs

This directory contains the deliverables from
`agent/curriculum-agent-interview.md`.

The labs prepare for Applied AI and agent-engineering interviews. They may use
Astra through its public API and may integrate off-the-shelf workflow, RAG,
evaluation, hosting, and security infrastructure. They do not define Astra's
product backlog.

No lab may add an Astra production abstraction solely for convenience or
interview coverage. Any proposed Astra change must independently pass the
feature-admission gate in `agent/refs/Astra/CLAUDE.md`.
